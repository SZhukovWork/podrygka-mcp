# podrygka-mcp

[English](README.md) · **Русский**

[MCP](https://modelcontextprotocol.io)-сервер, который отдаёт LLM-агентам живые и
честно подписанные данные [podrygka.ru](https://www.podrygka.ru) — интернет-магазина
сети косметики «Подружка»: поиск по каталогу с фильтрами сайта, карточки товара с
объяснением каждой скидки, наличие в каждом магазине вашего города, сроки доставки и
отзывы, где собственный рейтинг варианта отделён от рейтинга всей линейки.

> Сторона покупателя, без входа: ни аккаунта, ни корзины. Сервер читает тот же
> JSON API, что и страницы сайта, обычным HTTP — браузер не нужен.

## Зачем этот сервер

Данные магазина легко получить и легко понять неправильно. Всё ниже найдено
сверкой ответов API со страницами, которые видит человек:

| Ловушка podrygka.ru | Что делает сервер |
|---|---|
| Каталог отвечает за **Москву**, если регион не передан; ручка наличия по магазинам берёт регион из кук и без них молча отдаёт Москву | Находит город через справочник самого магазина, передаёт регион в каждом запросе, сверяет ответ о магазинах со списком магазинов региона и отвергает чужой |
| «В 12 магазинах» — это весь **регион** (Екатеринбург + Первоуральск), а не город | Магазины города и остальной части региона — отдельными списками: штуки, уровень сайта (мало/средне/много), часы работы |
| Рейтинг и число отзывов в каталоге — **всей линейки**: у всех 20 оттенков помады «4.1 · 92» | `rating_line` так и подписан; `get_product` считает рейтинг варианта по его собственным отзывам и пишет «нет своих отзывов», а не подставляет рейтинг линейки |
| Счётчик виджета отзывов больше числа опубликованных (117 против 104) | Число берётся из опубликованной ленты |
| Оттенки и объёмы — отдельные артикулы с **разными ценами и остатками** (801–951 ₽ внутри одной линейки помад); одна линейка занимает несколько плиток выдачи | Плитки одной линейки склеиваются (`group_variants`), каждый вариант показан со своей ценой и остатком |
| С 9:00 до 12:00 МСК сайт показывает всем **утреннюю скидку −5 %**, в 12:00 она пропадает | `discount_kind: morning_5pct`, `price_after_morning_window_rub` и блок `morning_window` в каждом ответе |
| «Выгодная цена», «Выгодная пара» и «1+1=3» по правилам сети — **акции для владельцев карты**, но сайт показывает их цены и без входа | У каждой акции `requires_loyalty_card` и правило, на котором это основано, с пометкой «корзиной не проверено» |
| Скидки «Выгодной пары» и «1+1=3» считаются только в корзине | `price_effect` говорит, что в показанной цене их нет |
| Стоимость доставки видна только при оформлении | `cost_rub: null` с причиной, никогда не 0 |
| Без `showAll=true` ручка сроков теряет вариант «пункт выдачи», который показывает страница товара | Запрос делается так же, как на странице товара |
| Неизвестный магазин в фильтре **молча игнорируется** — «отфильтрованный» поиск отдаёт всё подряд | Магазин сверяется со списком магазинов региона; фильтры бренда, категории и акций проверяются по результатам |
| Сервис отзывов Aplaut отдаёт **email и телефоны** покупателей | Отзывы проходят через белый список полей: оценка, текст, плюсы, минусы, дата, verified, лайки, число фото, срок использования; есть тест с фейковыми ПДн |
| Рейтинг 0 означает «нет отзывов», а не ноль звёзд | Поля рейтинга тогда нет, `reviews_line: 0` |
| Цена в магазине может отличаться от онлайн-цены (так пишет сам сайт) | Сказано в `price_note` рядом с каждой ценой |

В каждом ответе есть `fetched_at` (UTC), `city` — город, для которого получены данные
(как его называет справочник магазина, и откуда взят выбор), `price_scope` и
`morning_window`.

## Инструменты

| Инструмент | Что возвращает |
|---|---|
| `search_products(query, page, sort, price_min, price_max, brand, category, in_store, promo_only, city, group_variants, limit)` | 20 плиток на страницу (так у сайта); сортировка `popular` / `rating` / `price_asc` / `price_desc`; `total_found`, `total_pages`, `has_more`. Фильтры: ценовое окно, бренд (название или `brand_code`), категория (название или `category_code`), магазин (`in_store`, id из `list_stores`), только акции с ценой. У товара: онлайн-цена, цена до скидки, `discount_kind`, акции с правилами карты, цена за 100 мл/г, рейтинг и отзывы линейки, число вариантов и их ценовой диапазон, онлайн-остаток, остаток и число магазинов в регионе, сроки доставки для города, ссылка |
| `get_product(article, city, include_variants, include_stores, include_description)` | Всё то же по одному артикулу плюс: рассрочка, каждый вариант (оттенок/объём) со своей ценой, остатком и сроками, остатки по магазинам (город отдельно от региона), способы доставки с `cost_rub: null`, рейтинги — `shown_on_site` (линейка), `line` (по звёздам) и `variant` (свои отзывы) — и характеристики (страна, тон, текстура, состав, способ применения, габариты и вес упаковки) |
| `get_reviews(article, scope, page, limit, sort)` | `scope=variant` (только отзывы этого артикула) или `line`; `sort=newest` или `helpful`; до 50 на страницу. Дата, оценка, текст, плюсы, минусы, `verified`, лайки/дизлайки, число фото, срок использования; распределение звёзд и среднее для охвата; рейтинг линейки, который показывает сайт. Без данных авторов |
| `get_store_availability(article, city)` | Штуки в каждом магазине города (адрес, уровень, часы, координаты), магазины остального региона, онлайн-склад отдельно |
| `list_stores(city)` | Магазины региона с id для `in_store`, адресами и числом товаров в наличии в каждом |
| `compare_products(articles, city)` | До 20 артикулов рядом за два запроса; артикулы, которых сайт не вернул, помечены с причиной |
| `find_city(query)` | Города справочника магазина с регионами; подсказывает, как назвать город-тёзку (`"Березовский, Свердловская область"`) |

## Требования

Замерено на Linux (CachyOS), Python 3.12, с домашнего IP в России:

| | |
|---|---|
| Python | ≥ 3.10, с [uv](https://docs.astral.sh/uv/) (или pip) |
| Браузер | **Не нужен**: обычный HTTP (`requests`) |
| Docker, дисплей | Не нужны |
| Диск | ≈33 МБ на окружение (`mcp`, `requests` и их зависимости); ≈0,1 МБ кеша в `~/.cache/podrygka-mcp` |
| Память | ≈73 МБ RSS после старта, ≈82 МБ после поиска и карточки товара |
| Старт | Сервер готов за ≈0,4 с (≈1,6 с через `uvx` из локальной копии, со сборкой) |
| Задержки | Между запросами к магазину пауза 1,5 с, поэтому время в основном — паузы: первый поиск с пустым кешем ≈7 с (город, гостевой токен, выдача, сроки доставки), следующие поиски ≈4 с, полная карточка ≈6–8 с. Сам HTTP-запрос — 0,1–0,8 с |
| Сеть | Работает с российского домашнего IP. Зарубежные, VPN- и датацентровые IP не проверялись; магазин за CDN NGENIX, который может их блокировать. Прокси — `PODRYGKA_PROXY` |

## Установка

Claude Code:

```bash
claude mcp add podrygka -- uvx --from git+https://github.com/SZhukovWork/podrygka-mcp podrygka-mcp
```

Любой MCP-клиент (`claude_desktop_config.json`, `.mcp.json`, …):

```json
{
  "mcpServers": {
    "podrygka": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/SZhukovWork/podrygka-mcp", "podrygka-mcp"]
    }
  }
}
```

Из локальной копии: `uv venv && uv pip install -e . && .venv/bin/podrygka-mcp`.

## Настройка (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PODRYGKA_CITY` | `Екатеринбург` | Город по умолчанию для наличия и доставки (любой инструмент принимает и `city`). Название — как в `find_city`; для тёзок добавьте `, <область>` |
| `PODRYGKA_MIN_INTERVAL` | `1.5` | Пауза между запросами к podrygka.ru, секунды. Не уменьшайте: лимиты магазин не публикует, а IP ваш |
| `PODRYGKA_PROXY` | — | Прокси, например `http://user:pass@host:3128` |
| `PODRYGKA_CACHE_DIR` | `~/.cache/podrygka-mcp` | Гостевой токен, ключ виджета отзывов, город, списки категорий и магазинов (файлы `0600`, каталог `0700`) |

| `PODRYGKA_LOG` | `INFO` | `DEBUG` пишет в stderr каждый запрос (путь, статус, время); токены и ключи в лог не попадают |

## Что означают цифры

- **`price_online_rub`** — крупная цена на странице товара для покупателя без входа.
  Для Москвы и Свердловской области она совпала на всех 184 сравнённых позициях;
  в магазине цена может отличаться. **`price_before_discount_rub`** — зачёркнутая цена.
- **`discount_kind`** — `promo`: акция сети («Выгодная цена», SALE); `morning_5pct`:
  утренняя −5 % (только с 9:00 до 12:00 МСК, потом цена станет
  `price_after_morning_window_rub`); `unknown`: скидка без метки акции, которую сервер
  не может объяснить; `none` — скидки нет.
- **`requires_loyalty_card`** — что говорят правила сети: `true` у «Выгодной цены»,
  «Выгодной пары», «1+1=3» и утренней скидки, `false` у SALE, `"unknown"` у подарков.
  Сайт показывает эти цены и без входа; что начислит корзина гостю — не проверено.
- **Персональная скидка по карте** (3–15 %) не входит в цену и без входа не считается;
  по правилам она не суммируется с акциями и не действует на CATRICE, ESSENCE, GILLETTE.
- **Рейтинги** — `rating_line` / `reviews_line` в поиске и `rating.shown_on_site` в
  карточке относятся к линейке (округлены до 0,1, как на сайте). `rating.line` — то же
  по распределению звёзд; `rating.variant` посчитан по собственным отзывам артикула
  (`computed: true`).
- **Наличие** — `online_qty`: единый онлайн-склад сети; `stores_qty_in_region` и
  `shops_in_region`: все магазины региона; `stores.in_city`: магазины этого города.
  `level` — оценка самого сайта.
- **Доставка** — `when` в формулировке сайта («сегодня», «завтра», «2 - 3 дня»);
  `cost_rub` всегда `null` (стоимость известна только при оформлении). Если сайт
  обещает самовывоз «сегодня», а в магазинах региона товара нет, у варианта есть пометка.
- **`unit_price`** — цена за 100 мл / 100 г / 1 шт, только если фасовка ровно один раз
  встречается в названии товара.

## Ограничения

- Неофициальный сервер: опирается на внутренние API сайта (`/api/v3`, JSON-RPC
  `/api/v2`) и виджет отзывов Aplaut, которые могут измениться в любой момент. Сайт
  переезжает с Bitrix на Next.js; разбор ответов вынесен в `parse.py` и покрыт тестами
  на записанных ответах.
- Только без входа: нет персональной цены по карте, промокодов, бонусов и итога
  корзины. «Выгодная пара», «1+1=3» и подарки считаются в корзине, здесь их итог не
  посчитан.
- Конец утреннего окна (12:00 МСК) наблюдался, начало (9:00) взято из правил сети.
  Начислит ли корзина гостю утреннюю цену или «Выгодную цену» — не проверено.
- Собственный API отзывов магазина (`/api/v3/content/reviews`) сейчас отвечает 500;
  отзывы берутся из Aplaut. Сервер раз в час пробует API магазина; разбор его ответа
  написан по JavaScript сайта, а не по реальному ответу. В охвате `line` отзыв не
  привязан к оттенку.
- В списке магазинов (`list_stores`) нет часов работы, и не у всех адресов указан
  город; часы есть в `get_store_availability`.
- Истории цен, штрихкодов (EAN) и артикулов производителя у сайта нет.
- Подробно проверены только Москва и Свердловская область.
- Каталожный API не возвращает эхом регион, для которого ответил. Сервер передаёт
  регион в каждом запросе и сверяет то, что можно сверить: название города из
  справочника магазина, магазины в ответе о наличии — со списком магазинов региона,
  число магазинов в карточке — с числом магазинов в списке.
- `robots.txt` запрещает `/api/v3`. Используйте сервер для личного сравнения цен с
  человеческой частотой запросов.

## Планы

- **Позже: необязательный режим аккаунта** (по умолчанию выключен): один раз войти,
  чтобы видеть свою цену по карте и точную стоимость доставки.
- **Позже: корзина** поверх режима аккаунта.
- Оформление заказа, оплата и смена адреса доставки — сознательно вне планов.

## Разработка

```bash
uv venv && uv pip install -e '.[dev]'
.venv/bin/pytest            # офлайн-тесты на записанных ответах (без сети)
.venv/bin/pytest -m live    # сквозной прогон по MCP stdio против живого podrygka.ru (~25 запросов, ~40 с)
```

Устройство: `client.py` (политика запросов: паузы, гостевой токен, один повтор,
проверки правдоподобия, кеши), `parse.py` (чистые функции над JSON магазина: цены,
акции, рейтинги, наличие, магазины, отзывы), `server.py` (инструменты). Фикстуры в
`tests/fixtures/` — записанные и урезанные ответы; данные авторов отзывов удалены.

## Оговорка

Сервер не связан с «Подружкой» и Aplaut. Он использует недокументированные
внутренние ручки сайта магазина и рассчитан на личное использование с человеческой
частотой запросов. Соблюдайте условия использования магазина.
